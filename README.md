# POO-26-PD2

Calculadora de escritorio en Java (Swing) que sigue el patrón **Modelo-Vista-Controlador**. Permite sumar, restar, multiplicar y dividir, y limpiar el total. Usa `BigDecimal`, por lo que soporta enteros largos y decimales con precisión. La división se calcula con 10 decimales y redondeo `HALF_UP`.
